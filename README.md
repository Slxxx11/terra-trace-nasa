# TERRA-TRACE: Earth System Trend Detective

## The Problem
Climate and environmental changes happen constantly across the globe, but raw NASA satellite data is extremely complex. Scientists spend years analyzing these datasets, making it nearly impossible for regular people, students, and teachers to understand what is really happening to our planet.

## Our Solution
TERRA-TRACE is an interactive, user-friendly "mission control" web dashboard designed for everyone. It translates complex Earth telemetry into clear, visual insights. Users can compare two regions side-by-side (such as the Tian Shan glaciers and the Aral Sea basin), view dynamic charts, automatically calculate linear trends with statistical significance (p-value), and fetch live satellite data directly from the NASA POWER API for any coordinates on Earth.

## Tools & Technologies Used
- **HTML5 & CSS3:** Custom responsive layout with a modern Glassmorphism UI design.
- **JavaScript (ES6+):** Statistical trend calculation algorithms (linear regression & p-value) and dynamic UI state management.
- **Chart.js:** Interactive data visualization and multi-region comparison graphs.
- **NASA POWER API:** Real-time satellite meteorology and solar telemetry integration.
- **Bilingual Support:** Instant switching between English and Russian interfaces.
